## 3. 排版

| 级别 | 字号 | 行高 | 用途 |
|---|---|---|---|
| body | 12 | 16 | 正文、标签、表格 |
| tiny | 10 | — | 快捷键提示、状态栏 |
| title | 14 | — | 应用名、面板标题 |

- 字重：400 常规、500 半粗（方法名、选中项）、600 粗（应用名、面板标题）。
- 字体：原版 `Inter Variable` / `Roboto Mono Variable`；apigo 内嵌 `resources/HarmonyOS_Sans_SC.ttf`，启动时经 `ui.RegisterFont` 注册为 `HarmonyOS Sans SC`，并写进主题的 `Font`（`design.FontFamily`），所以中英文与数字都用它；URL、JSON、请求体仍用系统 `"monospace"`。系统没有可注册字体的文本引擎时回落系统字体。**字形宽度与原版仍有差异**，见 §6。

## 4. 栅格与尺寸

间距基数 4（`Spacing = 4`）：`p-2`=8、`p-4`=16、`gap-2`=8。圆角 4，边框 1。

| 区域/控件 | 尺寸 | 说明 |
|---|---|---|
| 集合标签条 | 高 40 | 主窗口按钮、打开的集合（名称 + ×、右键弹出自绘菜单；超出时横向滚动、无滚动条）、`…`（最近关闭）、右侧设置齿轮；当前标签取强调色 |
| 单个集合标签 | 最宽 240 | 名字整名显示；超过上限时按测量宽度截断并以 `…` 收尾（`design.CollectionTabMaxWidth`） |
| 集合工作区左右边距 | 12 | 左右两列整体内缩，不贴窗口边缘 |
| 开始提示面板 | 居中 | 集合刚打开、还没选接口时占满请求区（**连请求页签条一起**，此时没有页签也没有环境下拉）：标题「还没有打开接口」+ 一行说明，下面是四行「动作 + 按键」提示（新建接口 / 打开已有接口 / 发送请求 `Ctrl` `↵` / 保存接口 `Ctrl` `S`），按键画成带边框的小方框；关掉最后一个页签就回到它 |
| 左侧接口树 | 宽 240 | 头部 48（搜索框 + 历史按钮），下面是「根目录」+ 子文件夹 + 叶子接口树，高度铺满；每层缩进 12；`根目录` 行尾是「筛选」与「新建」两个按钮、**没有「⋮」**（根目录是集合自己的目录，没有可重命名/移动/删除的东西），子文件夹行尾是「新建」与「⋮」；行尾这组图标间距 2、按钮 18-22 见方，标题里箭头与文件夹图标间距 4；行悬浮换底色，当前标签对应的接口行取强调色；整行即按钮、整行手型指针；接口与文件夹行尾都有**竖向的「⋮」**按钮打开行菜单（`icons.MoreVertical`，只有树里是竖向；顶栏「更多」与集合行的「…」仍横向）；右键不再弹菜单 |
| 右侧请求页签 | 高 40 | 请求面板顶部：标签在左横向滚动（单个标签最宽 260、不画滚动条），右端只有环境选择器；**没有打开任何接口时整条不画**（请求区只剩开始提示） |
| 状态栏 | 高 32 | 左右内边距 8 |
| 请求行 | 高 40 | 方法框宽 104，内边距 12，与 URL、发送按钮间距 8 |
| 面板内边距 | 16 | 请求/响应面板一致 |
| 请求/响应分栏 | 默认 55/45 | 可拖拽，比例持久化 |
| 响应 meta 栏 | 高 44 | 内边距 16 |

```text
┌──────────────────────────────────────────────────────────┐
│ 主窗口 │ 示例接口集 × │ … │                     ⚙     │ 集合条 40
├──────────────┬───────────────────────────────────────────┤
│ 搜索 ⌕        │ GET Untitled ×│POST Untitled ×│+  本地 ▾ ◉ │ 请求页签 40
│              ├───────────────────────────────────────────┤
│ ▾ 根目录 5 ⌗ +│ Request pane (55%)                        │
│   ▾ 设备 2   │  ┌ method 104 ┐ ┌ URL ─────┐ ┌ Send ┐       │
│     订阅事件 │  Params Headers Body …                     │
│   ▾ 用户 1   │────────────────────────────────────────────│
│     查询Schema│ Response pane (45%)                       │
│   GET 列出宠物│  meta 44 / body                           │
│   POST 新建宠物│                                           │
│ (240, 铺满)  │                                            │
├──────────────┴────────────────────────────────────────────┤
│ Footer 32                                                │
└──────────────────────────────────────────────────────────┘
```

左列整列是接口树：头部只有搜索框与历史按钮（没有标题），下面是「根目录」——集合自己的目录，默认展开，行尾是筛选与新建菜单（菜单里先是「新建文件夹」，再是六种接口类型）；再下面是子文件夹与叶子接口，每层缩进 12，文件夹行尾只有新建菜单。右侧是请求面板：顶部一行请求页签（右端环境选择器），下面是该页签的请求内容与响应分栏。

请求标签条横跨整行（标签与右端环境选择器同一行）；接口面板在它下面左侧，高度从标签条一直铺到状态栏，与右侧请求/响应区并排。

请求标签条归左列（接口面板之上），环境条归右列顶部——两者不在同一行，互不重叠；整块两列区域左右各留 12 DIP。

主窗口（没有打开的集合时）是整块内容区：标题 + 「导入集合」「新建集合」，下面是集合列表（图标、名称、HTTP、接口数、打开、`…`）；无集合时居中引导，「新建集合」打开命名弹窗（标题、标签输入、保存/取消）。

## 5. 组件与行为清单

| 集合重命名 | 行尾菜单的 `重命名集合` 打开与新建集合同一个弹窗（标题改「重命名集合」、预填当前名称）；改名同时重命名集合目录，`.env/`、接口文件与 `apigo.yaml` 跟着搬（`store.renameCollection`），已打开的集合、工作区与标签跟到新 id | 完成 |

## 6. 已知差异

| 差异 | 原因 | 处理 |
|---|---|---|
| 字形宽度与原版不同 | 原版内嵌 Inter Variable，apigo 内嵌 HarmonyOS Sans SC（中文字形更贴合，拉丁字母略宽） | 以尺寸与色值为准；关键标签 `SingleLine` + 省略号；标签页给 `design.TabMinWidth` 兜底；不再追求逐字对齐 |
| URL / Body 内 `{{var}}` 无法内联着色 | `ui.TextInput` 不支持富文本 | 首版发送前校验并 Toast 提示；后续用 overlay 方案 |
| 应用内菜单不再是系统菜单 | MyGo 系统菜单只支持纯文本、无图标 | 集合行、集合标签右键、请求标签右键、方法下拉、类型筛选、行尾新建都用 `view_menu.go` 的 `popoverMenu`/`Popover` 自绘；应用里已没有 `ContextMenu` |
| 删除集合是伪删除 | 误删一个集合会连带丢掉整目录的接口与环境，代价太高 | 确认后只把集合记进数据目录根的 `hidden.yaml` 并从列表移除，目录、接口文件与环境文件原地保留；想找回就删掉那一行 |
| 请求标签无拖拽重排 | TabsBase 无重排能力 | 首版不做，列入后续 |
| 请求体格式改为胶囊行、不再是下拉 | 图 2 的格式选择是一整行胶囊，选中的填色；下拉在这个位置反而多一次点击 | `view_request.go` 的 `bodyFormatStrip` 直接铺出九种格式（`bodyFormats` 单一真相源），右端补上该格式的 Content-Type 与必填星号 |
| Binary / msgpack 只能选、不能发 | 需要选文件并按字节发送；这两个格式目前还没有字节编辑器（form-data 的文件字段已经能选文件并上传） | 选中时显示「需要选择文件，暂未实现」，`bodyReader` 不发送 body 也不带 Content-Type |
| GraphQL 用 JSON 高亮 | MyGo 0.6.0 的编辑器语法表里没有 GraphQL | 用 JSON 语言渲染 GraphQL 文档（`{"query":…,"variables":…}`），发送前按 JSON 校验、Content-Type 为 `application/json` |
| 选「跟随系统」后无法再随桌面变化 | `SetTheme` 之后无法交还给系统主题（MyGo 没有 reset） | 启动时取桌面亮暗并下发我们自己的主题（控件与自绘配色一致），会话内固定；重启恢复跟随 |
| 响应体整篇跨行选中受限 | 虚拟化列表只含可见行 | Raw 视图用只读编辑器（自带查找与选中） |
| 集合文件变化靠轮询发现 | `mygo.WatchFiles`（0.5.5 起就有）本可递归监听目录，当前实现选择了轮询，尚未换成监听 | 打开集合时整份重读一次（`reloadCollection`）；此后每 1.5 秒比对一次「文件名 + 大小 + 修改时间」的签名（`treeSignature`），变了才重读，`c.After` 维持这次重绘；重读后树表随磁盘更新，接口没了的标签退回草稿 |
| 原子写入的临时文件放在 `.tmp` | 原地写 `xxx.yaml.tmp` 会在接口目录里留下半截文件 | `writeYAML` 与上传复制都先写到所属集合根目录的 `.tmp/`，再 rename 到位；读取跳过点开头的目录，崩溃残留的临时文件在打开集合时清掉（`removeTempFiles`） |
