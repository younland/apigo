## 3. 排版

| 级别 | 字号 | 行高 | 用途 |
|---|---|---|---|
| body | 12 | 16 | 正文、标签、表格 |
| tiny | 10 | — | 快捷键提示、状态栏 |
| title | 14 | — | 应用名、面板标题 |

- 字重：400 常规、500 半粗（方法名、选中项）、600 粗（应用名、面板标题）。
- 字体：原版 `Inter Variable` / `Roboto Mono Variable`；apigo 用系统字体 + `"monospace"`（Mono 用于 URL、JSON、请求体）。**字形宽度存在已知差异**，见 §6。

## 4. 栅格与尺寸

间距基数 4（`Spacing = 4`）：`p-2`=8、`p-4`=16、`gap-2`=8。圆角 4，边框 1。

| 区域/控件 | 尺寸 | 说明 |
|---|---|---|
| 集合标签条 | 高 40 | 主窗口按钮、打开的集合（名称 + ×、右键菜单）、`…`（最近关闭）、右侧设置齿轮 |
| 集合工作区左右边距 | 12 | 左右两列整体内缩，不贴窗口边缘 |
| 左侧接口树 | 宽 240 | 头部 48（接口管理 + 搜索框 + 历史），第二行右对齐「筛选/新建文件夹/新建接口」，下面是「根目录」+ 子文件夹 + 叶子接口树，高度铺满；每层缩进 12 |
| 右侧请求页签 | 高 40 | 请求面板顶部：标签在左横向滚动，右端环境选择器与隐藏值按钮 |
| 状态栏 | 高 32 | 左右内边距 8 |
| 请求行 | 高 40 | 方法框宽 104，内边距 12，与 URL、发送按钮间距 8 |
| 面板内边距 | 16 | 请求/响应面板一致 |
| 请求/响应分栏 | 默认 55/45 | 可拖拽，比例持久化 |
| 响应 meta 栏 | 高 44 | 内边距 16 |

```text
┌──────────────────────────────────────────────────────────┐
│ 主窗口 │ 智慧康养机器人 × │ … │                     ⚙     │ 集合条 40
├──────────────┬───────────────────────────────────────────┤
│ 接口管理      │ GET Untitled ×│POST Untitled ×│+  本地 ▾ ◉ │ 请求页签 40
│ 搜索 筛选    ├───────────────────────────────────────────┤
│ ▾ 根目录 5   │ Request pane (55%)                        │
│   ▾ 设备 2   │  ┌ method 104 ┐ ┌ URL ─────┐ ┌ Send ┐       │
│     订阅事件 │  Params Headers Body …                     │
│   ▾ 用户 1   │────────────────────────────────────────────│
│     查询Schema│ Response pane (45%)                       │
│   GET 列出宠物│  meta 44 / body                           │
│   POST 新建宠物│                                           │
│ (240, 铺满)  │                                            │
├──────────────┴────────────────────────────────────────────┤
│ Footer 32                                                │
└──────────────────────────────────────────────────────────┘
```

左列整列是接口树：「根目录」是集合自己的目录，默认展开，下面是子文件夹与叶子接口，每层缩进 12，文件夹行尾有「新建接口」；右侧是请求面板：顶部一行请求页签（右端环境选择器），下面是该页签的请求内容与响应分栏。

请求标签条横跨整行（标签与右端环境选择器同一行）；接口面板在它下面左侧，高度从标签条一直铺到状态栏，与右侧请求/响应区并排。

请求标签条归左列（接口面板之上），环境条归右列顶部——两者不在同一行，互不重叠；整块两列区域左右各留 12 DIP。

主窗口（没有打开的集合时）是整块内容区：标题 + 「导入集合」「新建集合」，下面是集合列表（图标、名称、HTTP、接口数、打开、`…`）；无集合时居中引导，「新建集合」打开命名弹窗（标题、标签输入、保存/取消）。

| 主窗口 | 头部 `导入集合`（占位）与 `新建集合`（弹出命名弹窗：宽 420、顶部居中、标题居中、标签字段、按钮右对齐）；集合列表（名称、HTTP、接口数），`打开` 进入集合，`…` 删除；无集合时隐藏头部的导入/新建，居中展示图标块、标题、说明与「新建集合 / 从集合文件导入」 | 完成 |
| 接口树 | 「根目录」（集合自己的目录，有接口数、可折叠、行尾 `+`）+ 子文件夹 + 叶子接口；子文件夹可折叠、行尾 `+` 在其中新建接口；搜索与类型筛选作用于所有层级 | 完成 |

| 请求标签页 | 每个集合一组，横跨整行；新建（+）、点击切换、关闭（仅选中项显示 ×）、未选中且有内容显示圆点、标签间 1px 分隔线、选中项顶部 2px 强调色线；切换/新建/复制/关闭时把当前标签写回它的接口文件 | 完成 |

| 设置弹窗 | 外观循环、数据目录、版本 | 完成 |

| 请求行 | 方法下拉（彩色、104 宽）、URL 输入（mono）、发送（强调色，Ctrl+Enter） | 完成 |

## 6. 已知差异

| 差异 | 原因 | 处理 |
|---|---|---|
| 字形宽度与原版不同 | 使用系统字体，未内嵌 Inter | 以尺寸与色值为准；关键标签 `SingleLine` + 省略号；不再追求逐字对齐 |
| URL / Body 内 `{{var}}` 无法内联着色 | `ui.TextInput` 不支持富文本 | 首版发送前校验并 Toast 提示；后续用 overlay 方案 |
| 菜单项无图标 | MyGo 系统菜单只支持纯文本 | 方法下拉、集合菜单用 `Popover` 自绘 |
| 请求标签无拖拽重排 | TabsBase 无重排能力 | 首版不做，列入后续 |
| 选「跟随系统」后无法再随桌面变化 | `SetTheme` 之后无法交还给系统主题 | 记住最后一次系统外观，会话内保持不变；重启恢复跟随 |
| 响应体整篇跨行选中受限 | 虚拟化列表只含可见行 | Raw 视图用只读编辑器（自带查找与选中） |

## 7. 更新流程

1. **量**：在基线截图上标区域矩形、间距、字号、色值，更新本文件 §2–§4。
2. **建**：先静态像素布局，与基线并排截图达标后再接数据与交互。
3. **照**：离屏快照自动回归（`APIGO_SHOTS=docs/shots/<milestone> go test -run TestShots .`），真实窗口截图人工核验。
4. **记**：任何偏差记入 §6，不允许无声漂移。
